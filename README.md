# IPTV Матч-центр

Electron-приложение: расписание, счёт и статус футбольных матчей — с публичного API FotMob, без ключа и аккаунта.

**Турниры по умолчанию** (полный список — `electron/fotmob.js` → `COMPETITIONS`; можно выключать по одному в интерфейсе, кнопка «Настройки», см. ниже):

- Топ-5 лиг: Англия (АПЛ + Чемпионшип), Испания, Италия, Германия (+ 2. Бундеслига), Франция
- Плей-офф топ-дивизиона — только у Германии и Франции (`Bundesliga Qualification`, `Ligue 1 Qualification`): у остальных из топ-5 такого турнира на FotMob просто нет
- Лига чемпионов / Лига Европы / Лига конференций + их квалификационные раунды
- Шотландия, Португалия, Нидерланды, Бельгия, Турция, MLS
- Кубки и суперкубки — только топ-5 и Россия
- Россия: РПЛ, Кубок, Суперкубок, ФНЛ, стыковые матчи
- Бразилия и Аргентина: только главная лига, без кубка
- Кубок Либертадорес

**Каналы** — из твоего M3U-плейлиста; привязка к трансляции — через EPG (`url-tvg` в плейлисте): для каждого матча ищем передачу с этими же командами на всех каналах плейлиста, без предфильтра «это спортивный канал» (он терял матчи на нейтральных каналах вроде Первого).

**Интерфейс и плеер** — окно приложения показывает только ленту матчей, прижатую к левому краю экрана. Воспроизведение — через VLC: он открывается отдельным независимым окном ОС рядом с приложением (не встраивание — обычное окно VLC со своими элементами управления, которое можно двигать/ресайзить как угодно). Причина отказа от `hls.js`/MSE — часть потоков (interlaced 1080i) не проигрывались вообще, VLC играет их нормально. Требует установленный VLC. Кэш лежит в JSON.

**Избранное** — звезда в углу карточки добавляет матч в избранное; в момент начала избранного матча приходит desktop-уведомление.

**Автообновление** — приложение само проверяет новую версию на GitHub Releases при запуске и предлагает перезапуск для установки, когда она уже скачана.

## Скачать готовую сборку

Установщик и портативная версия — на странице [Releases](https://github.com/eonyushkin-commits/iptv-match-center/releases/latest). Сборка не подписана, поэтому при первом запуске SmartScreen покажет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

## Запуск из исходников

```bash
npm install
npm start
```

В интерфейсе кнопкой **Настройки** задаются:

- **Плейлист** — файл (кнопка «Обзор…») или прямая ссылка
- **EPG** — необязательно, файл или ссылка; если не указан, берётся `url-tvg` из плейлиста
- **Путь к VLC** — необязательно, иначе ищется автоматически
- **Турниры** — чек-лист, сгруппирован по стране как у FotMob; по умолчанию включены все, галочку можно снять с любого

Всё сохраняется в конфиг сразу при нажатии «Сохранить». Плейлист можно и просто положить файлом `playlist.m3u8` рядом с `package.json`.

На Windows нужен Node 18+ (`winget install OpenJS.NodeJS.LTS`), остальное одинаково в PowerShell и cmd.

## Сборка .exe

```powershell
npm install
npm run dist
```

В `dist/` появятся установщик `IPTV-Match-center Setup <версия>.exe` (NSIS, ставится в профиль пользователя, без прав администратора) и одиночный `IPTV-Match-center-portable-<версия>.exe` — версия берётся из `package.json`.

Собирать надо на Windows. Кросс-сборка с Linux формально возможна через Wine, но подписи и иконки там ломаются чаще, чем экономят время.

Сборка не подписана, поэтому при первом запуске SmartScreen покажет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае». Убирается только покупкой сертификата подписи кода.

В упакованном виде конфиг и кэш лежат в `%APPDATA%\iptv-match-center\` — папка `app.asar` доступна только на чтение.

EPG-фид качается и кэшируется на 6 часов (обычно 30–170 МБ в распакованном виде), так что первое «Обновить» после запуска может занять минуту-другую; дальше — из кэша, почти мгновенно.

## Настройка

`config.json`:

| Поле | Смысл |
|---|---|
| `playlistPath` | Путь к M3U-плейлисту либо прямая `http(s)`-ссылка на него — тот же смысл, что и поле «Плейлист» в диалоге «Настройки» |
| `epgUrl` | Необязательный оверрайд адреса EPG — нужен, только если плейлист не объявляет `url-tvg`; то же самое поле «EPG» в диалоге «Настройки» |
| `streamUserAgent` | User-Agent для VLC (`--http-user-agent`) — на случай, если провайдер режет UA по умолчанию |
| `vlcPath` | Путь к `vlc.exe`, если он не в стандартном `C:\Program Files\VideoLAN\VLC\` — то же самое поле в диалоге «Настройки» |
| `disabledCompetitions` | Список id турниров, отключённых чек-листом в «Настройки» (`electron/fotmob.js` → `COMPETITIONS`); без этого поля включены все |

## Как обновляются данные

Два независимых цикла, разной частоты под разные вещи:

- **Расписание и EPG** (какие матчи вообще есть, на каких каналах) — при запуске приложения, раз в час и по кнопке «Обновить». Меняется медленно, чаще пересобирать смысла нет.
- **Счёт, статус и минута** уже найденных матчей — раз в 3 минуты, отдельным лёгким циклом: без пересборки списка турниров и без EPG, точечным запросом `matchDetails?matchId=` только для матчей, которые уже начались и ещё не завершились (обычно 1–5 штук, не сотни). Матч, ещё не начавшийся, вообще не трогается — его время начала и так уже известно.

Оба API-источника (FotMob и EPG-фид) неофициальные (как раньше были Sofascore и ESPN у первого) — если однажды сломаются, соответствующая часть данных перестанет обновляться, но остальное приложение не пострадает. Стадион через `matchDetails` не запрашивается — строка стадиона просто не выводится.

Канал под матч ищется через EPG (`electron/epg.js` → `findBroadcastChannels()`):

- `tvg-id` в плейлисте почти всегда совпадает с `channel id` в фиде того же провайдера
- совпадение ищется в окне ±90 минут от начала матча, где заголовок называет обе команды — без отбора «спортивный/не спортивный» канал (он терял матчи на федеральных каналах и не переживал смену провайдера)
- сравнение имён — через `electron/normalize.js` (та же канонизация, что и для каналов: «Реал Мадрид» и «Real Madrid» сходятся); для двусловных названий достаточно совпадения одного слова, а не обоих — «CSKA Moscow» и кириллическая «Москва» транслитерируются по-разному («moscow» ≠ «moskva»), так что второй токен часто не совпадёт в принципе

## Как устроено воспроизведение (VLC)

Окно приложения — только лента матчей, шириной ~440px, прижатая к левому краю экрана на всю высоту рабочей области.

- Клик по каналу запускает `vlc.exe` отдельным процессом на URL потока
- `electron/vlc.js` через Win32-вызовы (`koffi`) находит его окно по PID и **один раз**, при первом запуске, ставит его рядом с окном приложения — занимает всё оставшееся место экрана
- дальше это обычное независимое окно ОС со своей рамкой и элементами управления VLC — двигать, ресайзить, разворачивать на весь экран можно как угодно, приложение больше его не трогает
- переключение канала при уже запущенном VLC переиспользует этот же процесс — URL меняется через его собственный HTTP-интерфейс управления (`pl_empty`+`in_play`), без пересоздания и перепозиционирования окна
- пауза/перемотка/громкость/полноэкранный режим — управление самого VLC, работает напрямую, когда его окно в фокусе

## Известные ограничения

- Требуется установленный VLC (`C:\Program Files\VideoLAN\VLC\vlc.exe` по умолчанию, путь можно переопределить в диалоге «Настройки» или напрямую в `config.json` → `vlcPath`). Без него плеер покажет ошибку.
- Окно VLC ставится рядом с приложением только один раз, при первом запуске потока — если до этого подвинуть окно приложения в другое место экрана, VLC подстроится под новую позицию только при следующем перезапуске плеера (закрыть VLC и включить канал заново), не на лету.
- И FotMob, и обходной путь для доступа к нему (`electron.net.fetch` вместо обычного `fetch`, см. «Грабли» в `CLAUDE.md`) — то же самое решение, что раньше было у Sofascore и ESPN, с тем же риском когда-нибудь без предупреждения сломаться.
- Транслитерация кириллицы — посимвольная, не официальная романизация: клубы с нестандартной англоязычной формой имени не совпадут, если их нет в небольшом словаре исключений (`RU_NICKNAMES` в `electron/epg.js`, см. `CLAUDE.md`).

## Файлы

```
electron/
  main.js         окно ленты матчей (прижато к левому краю экрана), IPC
  paths.js        пути для dev и для упакованной сборки
  sync.js         FotMob + EPG → guide.json (полный синк + лёгкое обновление счёта)
  fotmob.js       расписание/счёт/статус с FotMob (без ключа)
  epg.js          скачивание/кэш XMLTV, поиск каналов под известный матч
  vlc.js          запуск VLC отдельным окном ОС рядом с приложением (Win32 через koffi)
  playlist.js     парсер M3U (group-title/EXTGRP, префиксы стран, ранг качества), файл или URL
  normalize.js    канонизация имён (каналов и команд)
  store.js        JSON-кэш
  favorites.js    избранные матчи (id → favorites.json)
  broadcasters.js «где смотреть» с FotMob, по странам плейлиста
renderer/         только лента матчей, сам плеер полностью снаружи (см. «Как устроено воспроизведение»)
scripts/          epg-probe (разведка формата EPG-фида)
```

Кэш и плейлист в `.gitignore` — в URL каждого канала зашит твой токен доступа.
