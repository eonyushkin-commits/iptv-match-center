# Changelog

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/), на русском, как и весь остальной проект. Версии до 0.2.0 подробно не отслеживались (проект не вёл git-историю до первого пуша на GitHub) — 0.1.0 описана обобщённо, по фактическому состоянию кода на момент начала подробного версионирования.

## 1.1.1

- Убрана диагональная заливка фона карточки цветом турнира (`linear-gradient`/`color-mix()`) — по просьбе пользователя. Фон теперь плоский, левая цветная полоска-акцент осталась.

## 1.1.0

- Избранные матчи: звёздочка в углу карточки, список хранится в `favorites.json` (id матча от FotMob, стабилен между синками). Для избранного матча в момент начала (окно ±90 секунд, опрос раз в 30 секунд) приходит desktop-уведомление — Web Notification API, работает в рендерере нативно, без дополнительного IPC до main-процесса. Проверено вживую: клик по звезде не пробрасывается на клик по карточке (не запускает VLC), состояние переживает перезапуск (`favorites.json` на диске).
- Звезда — обычный flex-элемент ряда `card-top`, не `position: absolute` с фиксированным отступом: первая версия смотрелась криво рядом с бейджем LIVE (он выше обычного текстового бейджа даты — пилюля с паддингами, — и фиксированный `top` подходил только под один из двух случаев). Поймано визуально на живом скриншоте сразу после реализации, исправлено до первого релиза этой версии.

## 1.0.0

Первая стабильная версия — расписание из FotMob, сопоставление трансляций с EPG (транслитерация + короткие имена FotMob + словарь русских названий), независимый аудит пайплайна на реальных данных (0 подтверждённых пропусков), воспроизведение через VLC отдельным окном.

## 0.15.0

- Добавлен небольшой словарь русских названий команд (`RU_NICKNAMES` в `epg.js`) для клубов, чьё реальное русское название невозможно получить транслитерацией: Bayern München → «Бавария» (переведённое, а не транслитерированное имя региона), Paris Saint-Germain → «ПСЖ» (кириллическая аббревиатура), плюс ещё 7 клубов с диакритикой/короткими токенами, которые структурно не проходят через существующий Левенштейн-фолбэк (1. FC Köln, Beşiktaş, FC København, Başakşehir, Raków Częstochowa, Huracán, Çorum FK). Отдельно пробовали живой поиск через Wikidata (полные алиасы и только `labels`) — оба варианта откатили: один находил мусорные совпадения (общие слова вроде «of»/«v» из неотфильтрованных алиасов), другой терял уже работающие трансляции без транслитерационного фолбэка, и оба требовали ~8 минут резолва на холодную. Итоговый словарь — статический, без единого сетевого запроса при синке: список из 369 команд всех отслеживаемых турниров прошёл через код (не на глаз) на предмет отсутствия «безопасного» латинского токена, кандидаты сверены с реальной логикой сопоставления и живым поиском там, где написание было неочевидным (нашлась ошибка в собственной догадке — «Уракан», не «Ураган»).
- Независимый аудит: полное сравнение пайплайна сопоставления с сырыми данными FotMob и независимым сканированием заголовков EPG на другом источнике (`epg.team/7.7.xml`) — 0 подтверждённых пропусков на 221 реальном матче.

## 0.14.0

- Исправлен обратный баг — недостающие трансляции, а не лишние: «Lille – Paris Saint-Germain» показывала 2 канала вместо реальных 5, потому что вещатели часто пишут «PSG», а не «Paris Saint-Germain», и короткое имя не участвовало в поиске вообще. FotMob уже отдаёт его бесплатно (`homeShort`/`awayShort`) — теперь используется наравне с полным именем при поиске трансляций.

## 0.13.0

- Исправлен баг ложных совпадений через Левенштейн-фолбэк на коротких названиях команд. «Lille» (5 букв) — единственный токен команды — совпадал по расстоянию 2 со случайными словами («killer», «hill», «will», «lale»), «Saint» (часть Paris Saint-Germain) аналогично («sin», «park», «cain», «sailent») — в сумме карточка Lille–PSG собрала трансляции на Baby TV, Disney Junior, FOX News и немецком детективном канале. Найдено целевым живым аудитом сопоставления против открытых источников (заодно независимо подтверждена корректность нескольких реальных трансляций, включая Lyon–Fenerbahçe на TRT/Canal+). Допуск по расстоянию Левенштейна теперь растёт с длиной токена (`~1 правка на 3 буквы`) вместо фиксированных 2 — сохраняет уже проверенные случаи (Barcelona/barselona, Juventus/yuventus, Newcastle United/Юнайтед), но больше не путает короткие слова со случайными совпадениями.

- Исправлен баг ложных совпадений в сопоставлении команд: короткие клубные суффиксы («FC» и т.п.) могли в одиночку выдать совпадение с полностью не относящейся к футболу передачей.

## 0.1.0

Базовая версия на момент начала подробного версионирования:

- Расписание, счёт и статус — с публичного JSON-API FotMob, без ключа и аккаунта.
- Каналы — из M3U-плейлиста пользователя; трансляция матча ищется через XMLTV EPG по совпадению названий команд в заголовках передач.
- Воспроизведение — через VLC отдельным независимым окном ОС (не встроенный плеер).
- Окно приложения — только лента матчей по турнирам, прижатая к левому краю экрана.
