# Changelog

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/), на русском, как и весь остальной проект. Версии до 0.2.0 подробно не отслеживались (проект не вёл git-историю до первого пуша на GitHub) — 0.1.0 описана обобщённо, по фактическому состоянию кода на момент начала подробного версионирования.

## 0.7.0

- Заголовок окна переносится ровно между «IPTV» и «Матч-центр», а не посередине слова.
- Путь к `vlc.exe` теперь можно задать прямо в интерфейсе — третьим полем в диалоге «Источники» (с кнопкой «Обзор…» и проверкой, что файл существует), а не только правкой `config.json` руками. Первая версия делала для этого отдельный диалог «Настройки» — объединено обратно в «Источники» по просьбе пользователя, одна точка входа вместо двух.

## 0.6.0

- Приложение переименовано в «IPTV Матч-центр» — включая внутренние идентификаторы (npm `name`, `appId`), из-за чего сменилась и папка данных (`%APPDATA%\iptv-match-center`).
- Первый пуш проекта в приватный репозиторий на GitHub; `config.json` с личными путями плейлиста выведен из-под git в пользу шаблона `config.example.json`.

## 0.5.0

- Синхронизация разделена на два независимых цикла: полное расписание (FotMob + EPG) обновляется при запуске, раз в час и по кнопке «Обновить», а счёт/статус/минута уже найденных матчей — отдельно, каждые 2–3 минуты, без пересборки списка турниров и без EPG.
- Обобщена работа с чужими провайдерами плейлиста и EPG: поддержан стандартный атрибут `group-title`, полностью убрана эвристика «это спортивный канал» (сканируются все каналы плейлиста), формат EPG-фида определяется по содержимому, а не по URL (обычный `.xml`, `.xml.gz`, `.xml.tar.gz`).
- Исправлен баг коллизии кэша EPG: имя файла кэша было фиксированным, из-за чего при смене EPG-провайдера в пределах 6-часового TTL приложение тихо отдавало фид предыдущего провайдера. Кэш теперь ключуется по URL.
- Исправлен баг ложных совпадений в сопоставлении команд: короткие клубные суффиксы («FC» и т.п.) могли в одиночку выдать совпадение с полностью не относящейся к футболу передачей.

## 0.4.0

- Живая минута матча (например, «67'») — точечный запрос к FotMob только по матчам в статусе «идёт сейчас».
- Добавлены главная лига и главный кубок Бразилии, Аргентины и Беларуси.
- Добавлены квалификации Лиги чемпионов/Лиги Европы/Лиги конференций, сама Лига конференций и Кубок Либертадорес.
- Исправлен баг в определении страны турнира: `COUNTRY_NAMES[code] ?? code` не отличал «код намеренно замаплен на null» от «кода нет в таблице» — карточки еврокубков показывали лишний префикс «INT -».

## 0.3.0

- Полный внутренний ребрендинг: Спортцентр/`sportcenter` → Матч-центр/`match-center` (npm `name`, `appId`, папка `%APPDATA%`).
- Осиротевшая папка данных прежнего имени вычищена вручную (реальный NSIS-инсталлятор ни разу не запускался — это был только профиль Electron).

## 0.2.0

- Функция архивных ссылок «С начала матча» убрана полностью — вместе с кнопкой, которая уже была снята из интерфейса ранее, удалён и весь backend (`scripts/probe-catchup.mjs`, соответствующий IPC, `timeshiftDays`).

## 0.1.0

Базовая версия на момент начала подробного версионирования:

- Расписание, счёт и статус — с публичного JSON-API FotMob, без ключа и аккаунта.
- Каналы — из M3U-плейлиста пользователя; трансляция матча ищется через XMLTV EPG по совпадению названий команд в заголовках передач.
- Воспроизведение — через VLC отдельным независимым окном ОС (не встроенный плеер).
- Окно приложения — только лента матчей по турнирам, прижатая к левому краю экрана.
